# Qué servicios de IA vender ahora (y cobrar caro)

El documento y la skill de Claude para elegir qué servicio de IA vender, entregarlo apoyándote en Claude y cobrarlo
por lo que vale.

| Parte | Qué tienes |
|---|---|
| Los servicios | Setter de WhatsApp/Instagram, automatizaciones con n8n, reactivación de base de datos, agentes de Claude para el negocio y la auditoría de IA como puerta de entrada: qué resuelve cada uno, para quién y cómo se mide |
| La entrega | Cómo montarlo con Claude paso a paso: demo, diagnóstico, construcción, pruebas y mantenimiento |
| El precio | Precio por valor (lo que le cuesta no hacer nada), tres opciones, montaje + mensualidad y una entrada pequeña con número de éxito |
| El prompt | Para pegarlo en Claude y que te guíe con tu caso |

Hecho por Denís Corral · [@deniscorralvillarraso](https://instagram.com/deniscorralvillarraso) · [Sell Your AI](https://sellyourai.io)

## Cómo usarlo

- **Solo leer:** abre [`DOCUMENTO.md`](DOCUMENTO.md). Al final está el prompt para pegar en Claude.
- **Como skill de Claude Code:**

  ```bash
  git clone https://github.com/deniscorral3am/servicios-ia-skill ~/.claude/skills/servicios-ia
  ```

  Abre Claude Code y escribe `/servicios-ia`.
